## 📖 项目简介

本项目整合了目前市面上多款好用的科研浏览器插件并进行针对性改进。我们致力于为华西科研人打造一款 **0广告、0干扰、极致纯净** 的科研论文辅助工具。

插件深度适配华西科研场景，内置了最新的 **华西期刊分级（2025版）** 与 **JCR 分区** 数据。目前已全面升级至 **v2.0 版本**（主要由 **Codex** 驱动开发与重构），新增了 **Zotero 一键文献导入**、**免费文献全文获取** 等实用功能，并对分区与影响因子（IF）标签进行了全新视觉美化。旨在让文献检索与阅读回归纯粹与高效，**祝大家科研顺利，多发好文！** ✨

## 🎉 v2.0 更新亮点

- 🎨 **全新 UI 美化**：重构了期刊分区与影响因子（IF）的徽章显示样式，配色更柔和醒目，页面排版更加整洁美观。
- 📚 **Zotero 一键导入**：支持在检索页面将文献及元数据快速导入本地 Zotero 文献库，大幅提升文献管理效率 *(注：使用此功能时请确保已在本地提前启动 Zotero 客户端)*。
- 🔓 **免费文献获取**：集成开放获取（Open Access）与免费全文检索通道，一键直达可用 PDF 全文，告别繁琐的找文献流程。
- 🤖 **Codex 强力驱动**：v2.0 核心架构与功能迭代主要由 Codex 辅助开发完成，代码更精简、运行更流畅稳定。

## ✨ 核心特性

- 🏥 **华西专属分级**：内置 2025 华西期刊分区（A–F 级）数据，浏览论文时直观展示，贴合院内考核与投稿需求。
- 📊 **主流分区覆盖**：同步涵盖最新 JCR 分区与影响因子（IF），搭配全新美化的视觉标签，核心评价指标一目了然。
- 📥 **高效文献工作流**：打通从“检索分流 -> 免费全文获取 -> Zotero 一键入库”的完整闭环，让文献收集一气呵成。
- 🛡️ **0广告 · 0干扰**：彻底剔除繁杂的商业推广、弹窗与冗余功能，保持页面清爽，专注文献阅读。
- 🚀 **持续进化**：结合 Codex 高效开发与华西师生的实际使用反馈，持续打磨插件体验。

## 📦 安装指南

> 🚧 *注：插件目前处于持续优化升级阶段，推荐通过开发者模式加载最新 v2.0 版本。*

1. 下载本仓库的最新源码（点击右上角 `Code` -> `Download ZIP` 并解压）或前往 [Releases](#) 页面下载最新 v2.0 打包文件。
2. 打开 Chrome 或 Edge 浏览器，在地址栏输入 `chrome://extensions/`（或 `edge://extensions/`）。
3. 开启右上角的 **“开发者模式” (Developer mode)**。
4. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**，选择解压后的插件文件夹即可使用。
5. *(可选)* 若需使用 **Zotero 导入** 功能，请在使用前保持本地 Zotero 桌面端处于运行状态。

## 🌐 Introduction

Evolved from and integrating several proven, user-friendly research extensions, **WCH-SciHelper** is a **100% ad-free, distraction-free** academic browser extension tailored specifically for the West China (WCH/SCU) research community.

Now upgraded to **v2.0** (primarily developed and refactored with **Codex**), the extension goes beyond built-in support for the **2025 West China Journal Grading System** and **JCR Quartiles**. Version 2.0 introduces **one-click Zotero import**, **free full-text retrieval**, and a **redesigned, modernized UI** for journal grading and Impact Factor (IF) badges. We aim to strip away unnecessary bloatware and provide a streamlined literature workflow. **Wishing everyone a smooth and productive research journey!** ✨

## 🎉 What's New in v2.0

- 🎨 **Redesigned Badges & UI**: Beautified the visual presentation of journal rankings and Impact Factor (IF) tags with cleaner layouts and intuitive color schemes.
- 📚 **Zotero Integration**: Quickly import references and metadata directly into your local Zotero library with one click *(Note: Please ensure the Zotero desktop application is running locally before using this feature)*.
- 🔓 **Free Full-Text Access**: Integrated free paper retrieval channels to help you locate and download available Open Access / free full-text PDFs effortlessly.
- 🤖 **Powered by Codex**: Major v2.0 feature upgrades and code refactoring are primarily driven by Codex, ensuring a lighter, faster, and more reliable experience.

## 🌟 Key Features

- 🏥 **West China Grading System**: Built-in support for the 2025 West China Journal Classification (Grades A–F), tailored specifically for institutional evaluation and submission needs.
- 📊 **JCR Quartiles & IF Integration**: Displays JCR quartiles and Impact Factors directly alongside your search results with freshly polished visual badges.
- 📥 **Seamless Literature Workflow**: Bridges the gap between literature screening, free full-text access, and Zotero reference management.
- 🛡️ **Zero Ads, Zero Distractions**: Completely free of commercial promotions, pop-ups, and bloated features. Pure focus on your research papers.
- 🚀 **Actively Upgrading**: Continuously optimized with Codex and real-world feedback from researchers at West China.

## 🛠️ Installation

> 🚧 *Note: This extension is under active optimization. Loading via Developer Mode is recommended.*

1. Download the latest source code (`Code` -> `Download ZIP` and unzip) or grab the latest v2.0 build from the [Releases](#) page.
2. Open Chrome or Edge and navigate to `chrome://extensions/` (or `edge://extensions/`).
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner and select the unzipped extension folder.
5. *(Optional)* To use the **Zotero Import** feature, please make sure your local Zotero desktop app is launched beforehand.
