## 📖 项目简介

本项目整合了目前市面上多款好用的科研浏览器插件并进行针对性改进。我们致力于为华西科研人打造一款**0广告、0干扰、极致纯净**的科研论文辅助工具。

插件深度适配华西科研场景，内置了最新的 **华西期刊分级（2025版）** 与 **JCR 分区** 数据。目前项目正在持续升级与优化中，旨在让文献检索与阅读回归纯粹与高效。

## ✨ 核心特性

- 🏥 **华西专属分级**：内置 2025 华西期刊分区（A-F 级）数据，浏览论文时直观展示，贴合院内考核与投稿需求。
- 📊 **主流分区覆盖**：同步涵盖最新 JCR 分区与影响因子（IF），核心评价指标一目了然。
- 🛡️ **0广告 · 0干扰**：彻底剔除繁杂的商业推广、弹窗与冗余功能，保持页面清爽，专注文献阅读。
- 🔧 **博采众长**：整合现有优秀科研插件的核心交互，开箱即用，轻量流畅。
- 🚀 **持续进化**：目前处于高频迭代升级阶段，不断根据华西师生的实际使用反馈打磨体验。

## 📦 安装指南

> 🚧 *注：插件目前处于持续优化升级阶段，暂推荐通过开发者模式加载。*

1. 下载本仓库的最新源码（点击右上角 `Code` -> `Download ZIP` 并解压）或前往 [Releases](#) 页面下载打包文件。
2. 打开 Chrome 或 Edge 浏览器，在地址栏输入 `chrome://extensions/`（或 `edge://extensions/`）。
3. 开启右上角的 **“开发者模式” (Developer mode)**。
4. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**，选择解压后的插件文件夹即可使用。

## 🌐 Introduction

Evolved from and integrating several proven, user-friendly research extensions, **WCH-SciHelper** is currently under active optimization to build a **100% ad-free, distraction-free** academic browser extension tailored for the West China (WCH/SCU) research community.

We aim to strip away unnecessary bloatware and provide a streamlined literature browsing experience, featuring built-in support for both the **2025 West China Journal Grading System** and **JCR Quartiles**.

## 🌟 Key Features

- 🏥 **West China Grading System**: Built-in support for the 2025 West China Journal Classification, tailored specifically for institutional evaluation and submission needs.
- 📊 **JCR Quartiles Integration**: Displays JCR quartiles and Impact Factors (IF) directly alongside your literature search results.
- 🛡️ **Zero Ads, Zero Distractions**: Completely free of commercial promotions, pop-ups, and bloated features. Pure focus on your research papers.
- 🔧 **Refined & Integrated**: Combines the best workflows from existing top-rated extensions with targeted performance improvements.
- 🚀 **Actively Upgrading**: Continuously optimized and iterated based on real-world feedback from researchers at West China.

## 🛠️ Installation

> 🚧 *Note: This extension is currently under active upgrade. Loading via Developer Mode is recommended.*

1. Download the latest source code (`Code` -> `Download ZIP` and unzip) or grab the latest build from the [Releases](#) page.
2. Open Chrome or Edge and navigate to `chrome://extensions/` (or `edge://extensions/`).
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner and select the unzipped extension folder.
