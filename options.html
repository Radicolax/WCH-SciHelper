安装后即显示 IF 数值和 JCR 分区，无需手动导入。数据来源为 ShowJCR 社区整理数据，源文件标注的指标年份为 2025。期刊详情中保留年份与来源，未提供分区的期刊会明确显示“未分区”。

自定义数据（可选）

可另行导入你有权使用的 CSV 或 JSON 数据。数据保存在本机，不会上传。IF 和分区标签会显示在论文详情和 PubMed 搜索结果中。

同一期刊每个学科一行，保留 JCR 年份。存在多个年份时，使用最新年份；同一年份优先采用自定义数据，并显示最佳学科分区，详情保留全部匹配学科。

CSV 字段：journal,issn,eissn,jif,jcr_quartile,jcr_year,category

journal,issn,eissn,jif,jcr_quartile,jcr_year,category
Example Journal,1234-5678,8765-4321,8.2,Q1,2025,Medicine

上面的记录仅展示文件格式。JSON 可使用记录数组或包含 records 数组的对象。ISSN 支持带连字符或连续 8 位格式。


一键保存到 Zotero

  1. 启动本机 Zotero 桌面端，选中要保存的文献库或分类。
  2. 在 Chrome 中打开单篇论文详情页。
  3. 点击 HX-Pure 工具栏图标，再点击“一键保存到 Zotero”。

保存文献题录和匹配到的 SCU、HX-2025、JCR 标签。普通网页按网页条目保存；搜索结果页请先进入单篇详情。

连接仅发送到本机 127.0.0.1:23119；有 DOI 时使用 Crossref 补全题录。此功能不自动下载全文 PDF，也不执行 Zotero Connector 的站点翻译器。
